# Changelog

All notable versions of Nerisse are documented here. Each release contains a complete standalone Codex v2 pet package.

## [v8.1.0] — Hologram Thinking

- Replaced the subtle standing running/working loop with the approved seated holographic sequence.
- Kept the completed-output review row unchanged, so both active work and review use the same requested animation.
- Preserved rows 0–6 and 8–10 pixel-identically from v8.
- Revalidated the complete 8×11 Codex v2 atlas with no errors or warnings.

## [v8.0.0] — Seated Hologram Review

- Replaced the stale standing review loop with a six-frame seated interaction.
- Added readable scan, tap, swipe, head-tilt, and blink beats.
- Kept the hard-edged hologram physically connected to her glove for clean transparency.
- Preserved rows 0–7 and 9–10 pixel-identically from v7.

## [v7.0.0] — Flirty Idle

- Rebuilt the idle row around a playful, expressive micro-performance.
- Improved the larger face presentation and subtle torso/hair motion.
- Preserved all non-idle animation rows from v6.

## [v6.0.0] — Wide & Short

- Returned to the detailed v4 visual identity.
- Shortened and widened the silhouette for more face room at pet scale.
- Refined the mature hourglass proportions while preserving the jellyfish haircut and outfit.

## [v5.0.0] — Large & Clean

- Simplified noisy skin, facial, and costume detail.
- Reduced palette complexity for improved downscaled readability.
- Increased face size and retained a compact hourglass silhouette.

## [v4.0.0] — Jellyfish HD

- Introduced the silver-and-blue jellyfish haircut.
- Shifted costume layers toward cool-blue translucent-looking materials.
- Reduced overall height and improved non-pixel rendering clarity.

## [v3.0.0] — Character Remake

- Rebuilt Nerisse with a more confident mature silhouette.
- Added shorter hair, revised outfit construction, and more expressive movement.
- Reworked the full v2 animation set around the new character design.

## [v2.0.0] — High Quality

- Moved away from the initial pixel-heavy appearance.
- Improved animation smoothness and corrected hover/jump presentation.
- Audited the standard animations and sixteen look directions.

## [v1.0.0] — Original Guardian

- First complete Nerisse desktop-pet release.
- Established the ethereal moonlit guardian identity.
- Included all nine standard animation rows and sixteen look directions.
